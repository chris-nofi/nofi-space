# x402 evidence API

> **Legacy (plan v1).** Superseded by `docs/09_PLAN_V2.md` and the v2 plan's pitch (§6). Kept for reference.

**Who pays:** institutions and their agents (EPS MERESE teams, irrigation users' boards, monitoring committees, insurers, researchers). **Never farmers.**

**What they buy:** a signed evidence pack for one plot and season (`GET /v1/evidence-pack?plot=<hash>&season=2027`), ~0.05 USDC.

## Flow (x402 v2 header names)
```
GET /v1/evidence-pack?plot=0xabc…&season=2027
← 402 Payment Required
  PAYMENT-REQUIRED: base64(JSON){
    "x402Version": 2,
    "accepts": [{ "scheme": "exact", "network": "eip155:<chainId>",
                  "asset": "<USDC address>", "amount": "50000",
                  "payTo": "<X402_PAY_TO>", "resource": "/v1/evidence-pack" }]
  }
→ (client signs an EIP-3009 transferWithAuthorization and retries)
  PAYMENT-SIGNATURE: base64(JSON payment payload)
← 200 OK + pack
  PAYMENT-RESPONSE: base64(JSON){ "success": true, "transaction": "0x…", "network": "eip155:<chainId>" }
```

## Modes in `oracle/earth_oracle/server.py`
- `X402_MODE=demo` (default): returns a spec-shaped 402; accepts any `PAYMENT-SIGNATURE` and returns a simulated `PAYMENT-RESPONSE`. Good for the video, clearly labeled simulated.
- `X402_MODE=facilitator` (Task T3.5): POST to the facilitator's `/verify`, serve the pack, then `/settle`.

## Facilitators
- **NØCHAIN:** self-host `x402-rs` configured with the L1 chain ID and USDC address.
- **Fuji / C-Chain:** use a facilitator listed on Avalanche's Builder Hub (e.g. Ultravioleta DAO, PayAI, thirdweb, x402-rs).
- Check the current x402 docs before building: https://docs.x402.org

## Agent demo
`oracle/scripts/coop_agent.py` — plays a utility's AI agent: requests a pack, receives 402, "pays", retries, verifies the evidence hash matches the on-chain attestation.
