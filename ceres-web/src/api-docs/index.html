x402 field API · Avalanche Fuji C-Chain

Pay-per-request NASA farm evidence

Look up a Moquegua field's Ceres Field Score or its full evidence bundle. Pay per request in Circle test USDC with an x402 signature; get the data, the Snowtrace payment receipt and the WaterProofRegistry proof.

Testnet demo pricing. Not a commercial offer. Farmers use the map and CERES free. We designed the API for insurers, lenders, co-ops and exporters; we have no paying customers on this testnet.

Free vs paid

Free · public

The farm dashboard, monthly headline scores with confidence and data gaps, dataset labels, strategy comparison, season view, and every evidence fingerprint (dataHash) with its on-chain record, checkable at /verify/. Served as precomputed public summaries (/data/public/summaries.json, schema ceres-public-summary.v1).

Paid · x402

Machine-readable score with component inputs, weights and quality reasons; and the complete canonical evidence record (source datasets, observation metadata, provenance) whose sha256 is the on-chain fingerprint. Only returned after the payment settles. The complete record is not available from any static URL.

Fuji testnet demonstration. Prices below are test USDC, not commercial prices; commercial pricing will be announced. Source NASA and partner datasets may be public: CERES charges for engineering, validation, standardized delivery and analysis, not for exclusive ownership of satellite data. Flow

# 1. ask
curl -i $BASE/v1/field/algarrobal/score
# → HTTP/1.1 402 Payment Required
#   PAYMENT-REQUIRED: base64({"x402Version":2,"accepts":[{"scheme":"exact","network":"eip155:43113",
#     "amount":"20000","asset":"0x5425…Bc65","payTo":"0x…","maxTimeoutSeconds":120,
#     "extra":{"assetTransferMethod":"eip3009","name":"USD Coin","version":"2"}}],"resource":{…}})

# 2. sign TransferWithAuthorization(from,to,value,validAfter,validBefore,nonce) with eth_signTypedData_v4
#    domain {name:"USD Coin", version:"2", chainId:43113, verifyingContract:0x5425…Bc65}

# 3. retry with the signature
curl -i $BASE/v1/field/algarrobal/score -H "PAYMENT-SIGNATURE: base64({x402Version:2, accepted:{…}, payload:{signature, authorization}})"
# → HTTP/1.1 200 OK   PAYMENT-RESPONSE: base64({success:true, transaction:"0x…", network:"eip155:43113"})
#   {"formulaVersion":"ceres-field-score.v1","score":…,"confidence":"low",…,
#    "proof":{"chainId":43113,"dataHash":"0x…","recordedOnChain":true|false|null,
#             "paymentTx":"0x…","paymentTxUrl":"https://testnet.snowtrace.io/tx/0x…"}}

A Node client is in space-apps-2026/avalanche/x402/client.mjs (payAndFetch(url, {wallet, chainId: 43113})). The browser flow with Core Wallet is on /pagar.

Proof fields

recordedOnChain: true
The bytes you bought hash to exactly what WaterProofRegistry stores for this field-month.
false
Paid and served, but this month is not anchored yet. We say so instead of hiding it.
null
No registry configured on this deployment.

Errors

402 + error
invalid_exact_evm_payload_signature (wrong domain/chain), …_nonce_used (replay), …_recipient_mismatch, …_authorization_value, insufficient_funds
404
Unknown field or month
503
oracle_not_configured (deployment missing X402_PAY_TO) or placeholder evidence refused
