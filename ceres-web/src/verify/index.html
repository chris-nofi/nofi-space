Comprueba que la evidencia no cambió

Cada mes, Ceres guarda la huella (sha256) del registro de evidencia completo de cada chacra en el contrato WaterProofRegistry de Avalanche (red de prueba Fuji). Aquí cualquiera puede comprobar, gratis y sin billetera, si una huella está registrada en la cadena. Anyone can check, free and without a wallet, whether a fingerprint is recorded on-chain.

Qué prueba esta página · What this page proves

1. «La huella está registrada en la cadena» (gratis): el contrato confirma que esta huella fue anclada para esta chacra y mes. · “The fingerprint is recorded on-chain” (free): the contract confirms this fingerprint was anchored for this field and month.

2. «Mi archivo de evidencia da esa huella»: requiere tener el archivo. Quien compra la evidencia por la API x402 recibe el JSON exacto; calcula sha256 del JSON con las claves ordenadas recursivamente y sin espacios, y compáralo. · “My evidence file hashes to that value” requires the file. A buyer of the x402 Evidence API receives the exact JSON; compute sha256 of the JSON with keys sorted recursively and no whitespace, and compare.

La huella prueba integridad (que esos bytes no cambiaron), no que las mediciones sean científicamente correctas. · The fingerprint proves integrity (those bytes did not change), not that the measurements are scientifically correct.
